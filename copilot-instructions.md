# Copilot Instructions

## Testing Requirements
- When modifying or adding behavior, create or update tests in the closest relevant test file.
- Run the most relevant focused tests after changes and report results.
- If tests are not feasible, explain why and propose an alternative verification step.
- Ensure all tests pass before finalizing changes.

## Code Quality
- Keep changes minimal and consistent with existing style.
- Avoid unrelated refactors.
- Prefer root-cause fixes over surface-level patches.
